# Third-party icons in this directory

The AI provider logos `openai.svg`, `claude-color.svg`, `grok.svg`, `perplexity.svg`,
`mistral-color.svg`, `deepseek-color.svg`, `copilot-color.svg`, `ollama.svg`, `anthropic.svg` and — since
SQEM-554 (c), for the MCP client tabs — `claudecode.svg`, `codex.svg` and `cursor.svg` are
byte-identical to [`@lobehub/icons-static-svg`](https://github.com/lobehub/lobe-icons) v1.97.0;
`gemini-color.svg` is the same drawing — only the gradient ids differ, most likely an earlier version of
that package (not verified). That package is published under the MIT licence reproduced below. Checked file by file on
2026-10-21 (SQEM-557; the three MCP client logos downloaded and checked 2026-10-22). VS Code has no logo
in that package, so its tab shows a neutral icon instead. `openrouter.svg` is **not** from that package — it is OpenRouter's own icon
(SQEM-031).

The licence covers the drawings as files. The logos themselves remain trademarks of their owners;
Sqemes uses them only to name and link to those products, never to suggest endorsement.
